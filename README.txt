ZULU 1 HAM DOG TUTOR
Personal spelling tutor for Miss Elian

HOW TO OPEN
Double-click index.html. It opens in a web browser (Chrome, Edge or Safari work best).
Turn the volume up. The tutor speaks with a UK female voice when one is installed on the computer.
An internet connection is needed only for the fancy fonts; everything else works offline.

SECTIONS
- My Words: type the weekly spelling words.
- Learn: hear each word, clap the chunks, memory tricks, silly letter stories, hidden words.
- Games: Spelling Bee, Unscramble, Missing Letters. Each letter typed is spoken aloud,
  and every answer is read back before Zulu says whether it is right.
- Revision: end-of-week recap and revision test with a certificate. Past weeks can be revised too.
- Rewards: stars, badges and Granny Beryl's treat.
- Beryl: set the treat, stars needed, voice, speaking speed, revision day.

Progress is saved in the browser on the device being used.

SIGNATURE CALL
Each session opens with Zulu 1's call sign in Morse code (Z --..  U ..-  L .-..  U ..-  1 .----)
then "This is Zulu one calling Miss Elian". The End session button plays the Morse call sign
again and says "Zulu one out".

ANDROID APP (APK)
The android folder holds the Android app. When this project is pushed to GitHub,
GitHub builds the APK automatically (see the Actions tab), and the file
Zulu1-HamDog-Tutor.apk appears under Releases. Download it on the Android phone and
tap it to install (allow "Install unknown apps" for the browser when asked).
