ZULU 1 HAM DOG TUTOR
Personal spelling tutor for Master Shakai Stoute

HOW TO OPEN
Double-click index.html. It opens in a web browser (Chrome, Edge or Safari work best).
Turn the volume up. The tutor speaks with a UK female voice when one is installed on the computer.
An internet connection is needed only for the fancy fonts; everything else works offline.

SECTIONS
- My Words: type the weekly spelling words.
- Learn: hear each word, clap the chunks, memory tricks, silly letter stories, hidden words.
- Games: Spelling Bee, Unscramble, Missing Letters. Each letter typed is spoken aloud,
  and every answer is read back before Zulu says whether it is right.
- Revision: end-of-week recap and revision test with a certificate. Past weeks can be revised too.
- Rewards: stars, badges and Granny Beryl's treat.
- Beryl: set the treat, stars needed, voice, speaking speed, revision day.

Progress is saved in the browser on the device being used.

SIGNATURE CALL
Each session opens with Zulu 1's call sign in Morse code (Z --..  U ..-  L .-..  U ..-  1 .----)
then "This is Zulu one calling Master Shakai Stoute". The End session button plays the Morse call sign
again and says "Zulu one out".

ANDROID APP (APK)
The android folder holds the Android app. When this project is pushed to GitHub,
GitHub builds the APK automatically (see the Actions tab), and the file
Zulu1-HamDog-Tutor.apk appears under Releases. Download it on the Android phone and
tap it to install (allow "Install unknown apps" for the browser when asked).

TWO STUDENTS
- index.html: Master Shakai Stoute's tutor.
- bubba/index.html: Master Bubba's tutor (Year 7 & 8, Key Stage 3). It adds subject word packs
  (Tricky Spellings, English, Maths, Science, History, Geography) with meanings, word-building tips
  (prefixes, roots, suffixes), meanings in the Spelling Bee, and a Meaning Match game.
  It is generated from index.html, so changes to the main tutor can be carried over.
Each student has a separate Android app, iPhone app and Windows package, with separate saved progress.

IPHONE SAFARI (website)

  Master Shakai Stoute: https://bajanbob.github.io/Zulu1/
  Master Bubba:         https://bajanbob.github.io/Zulu1/bubba/
Open the link in Safari, tap Share, then "Add to Home Screen" for a puppy icon.
The website updates by itself every time a change is pushed.

ZULU 1 PRO
Home shows "Zulu's plan for today": the words that need most practice and the activities to play,
each with a Start button. It works offline. Switch on Zulu 1 Pro in Beryl's corner to have the
plan, memory tricks and mistake explanations made by AI (Claude, by Anthropic).
Pro sends only spelling words and right/wrong counts; family names are removed first.
For a commercial setup, use the Pro service in the "server" folder (see server/README.md), so the
API key never sits on children's devices.

NAMES
Beryl's corner > Names: change the tutor's name (the Morse call sign follows it), the student's
name, the short name used in encouragement, and how the names should be spoken
(for example "Shakai=Shah-kye; Stoute=Stowt"). "Back to the original names" undoes it.

CHROMEBOOK
The website installs as an app on a Chromebook (Install icon in Chrome's address bar), using
manifest.webmanifest and the icons folder. For offline use, see chromebook/HOW TO USE ON A CHROMEBOOK.txt.
